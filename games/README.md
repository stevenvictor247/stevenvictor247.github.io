# Football Games app

Installable web app (PWA) served by GitHub Pages at https://stevenvictor247.github.io/games/

- `index.html`: the game picker (home screen start page). Add a card per game above the `GAMES` comment.
- `manifest.webmanifest`, `icons/`: app name and icons.
- `sw.js`: service worker. Pages and data load network first, so a pushed update shows up the next time the app opens; cached copies keep it working offline. Photos and icons are cache first.
- `head.inc`: the shared `<head>` (manifest, icons, iOS tags) to put at the top of every game page.
- `handoff/`: Hand-Off, the NFL chain game. Generated by `build/make_pwa.py` in /mnt/project-files/nfl-chain-game/ from the published game; don't edit by hand.

New game: put it in its own folder (`games/<name>/index.html`), start the page with `head.inc`, register `/games/sw.js` with scope `/games/`, and link back to `../`.
